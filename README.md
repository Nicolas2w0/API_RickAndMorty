# Rick and Morty — Busca de personagens

Aplicação web para consultar personagens do universo de **Rick and Morty**. O projeto utiliza a [Rick and Morty API](https://rickandmortyapi.com/) para buscar personagens pelo nome ou selecionar um personagem aleatório.

## Funcionalidades

- Busca de personagens pelo nome.
- Seleção de um personagem aleatório.
- Exibição da imagem e de informações como nome, identificação, status, espécie, gênero e origem.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Fetch API
- Rick and Morty API

## Como executar

1. Clone este repositório ou baixe os arquivos.
2. Abra `main.html` no navegador.
3. Digite o nome de um personagem e clique em **Buscar**, ou clique em **Aleatório**.

É necessária uma conexão com a internet para consultar a API.

## Objetivo

Projeto de estudo para praticar desenvolvimento front-end, manipulação do DOM e consumo de uma API REST com JavaScript.
